01The three kinds of points

Every number on the site comes from one place: the match results an organiser enters. From those, the site works out three things automatically.

A

Match points

Earned inside one event, match by match. They decide the event's own leaderboard.

B

Arena points

Earned once per finished event from your final rank. They decide the Top players rankings.

C

House points

The same final-rank points, split between a team's players and sent to each player's house.

02Event standings

Points for one match

match points = placement_points[ place ] + kills × kill_points
An organiser can type an exact points value for a row instead; that value wins.

Each event copies its game's table when it is created, and an admin can edit it per event. Keys can be single places ("1") or ranges ("5-8"). A place that is not in the table earns 0.

Points for the whole event

event points = sum of all match points + admin adjustment

The adjustment is for penalties or corrections (for example −5 for a late lobby join). It always needs a written note and is recorded in the audit log.

Ranking and tie-breaks

  1. More event points ranks higher.
  2. Tied on points: more wins (matches finished 1st, the "WWCD"/chicken dinners in battle royale).
  3. Still tied: more kills / finishes.
  4. Still tied: the better best placement in any single match.
  5. Still tied: they share the rank (two teams at 3rd, the next one is 5th).

Disqualified entries stay visible at the bottom marked DQ and get no rank. Before the first result, entries are listed by registration and every rank shows "–".

Every event leaderboard also shows the top three as podium cards (GOAT, 2nd, 3rd), and a signed-in player always sees their own position pinned, even when they are far down the list.

03Running any number of teams

Games fall into five formats. Each one has a rule for when more players register than fit in one lobby or one bracket.

Battle royale BGMI · Free Fire MAX

One lobby holds 16 squads (BGMI) or 12 squads (Free Fire MAX). With N squads and a lobby size L:

  • N ≤ L: one lobby plays 3–4 maps; standings are the sum over all maps.
  • N > L: make G = ⌈N ÷ L⌉ groups as evenly as possible. Each group plays the same number of maps. The top ⌊L ÷ G⌋ squads of each group (plus the best remaining by points, to fill the lobby) go to the final. Example: 40 BGMI squads → 3 groups of 14/13/13 → top 5 of each + the best 6th = 16 in the final.
  • Run qualifiers as their own event (or label matches "Group A – Map 1"), then enter final-lobby results under the final event. The final event's standings are the official result.

How to record it: when the bracket ends, enter one row per team in a match labelled Final placement: champion 1, runner-up 2, losing semi-finalists 3 (or play a 3rd-place match), quarter-final losers 5, round-of-16 losers 9. The default table then gives 10 / 7 / 5 / 2 / 1. Individual series can also be logged for history with explicit points of 0, so they do not double count.

One-on-one Chess · Clash Royale · eFootball · Real Cricket

Up to 16 players: a bracket, as above. More than 16: a Swiss event with ⌈log₂ N⌉ rounds (64 players → 6 rounds), win 1, draw ½, loss 0, entered round by round with explicit points. Chess runs on a lichess Swiss/Arena and the organiser copies the final table. eFootball groups use win 3, draw 1, loss 0.

Race and party Asphalt Legends · Stumble Guys

Every race or round is a match: Asphalt pays 10/8/6/5/4/3/2/1 for places 1–8; Stumble Guys pays 10/7/5. Races hold 8 (Asphalt) or 32 (Stumble Guys) players, so split bigger fields into heats, add up points across 3–5 races, and send the top of each heat to a final.

Room games Ludo King · skribbl.io

Ludo tables hold 4. skribbl rooms are capped by the organiser (about 8 works well). Winners of each table or room advance to the next round until one final table/room is left. That final's places 1–4 (or 1–8) are entered as the event result.

05Top players

When an event is marked Completed, every entry gets its final rank, and that rank earns Arena points from the event's House-points table (default 1st 10, 2nd 7, 3rd 5, 4th 4, 5th–8th 2, 9th–16th 1).

a player's Arena points = sum over completed events of points for their team's final rank
Every playing member gets the full amount (a winning squad of 4 gives each player 10). Subs get nothing.
  • Four tabs: All games · Solo (1 player) · Duo & 3v3 (2–3 players) · Squads & 5v5 (4 or more).
  • Order: Arena points › number of 1st places › number of podiums (top-3 finishes). Equal on all three = shared rank.
  • Shown: GOAT / 2nd / 3rd podium cards with avatar, house and points; ranks 4–100 as a list; the signed-in player's own rank and points are always pinned, even outside the top 100.
  • Banned players are removed from the rankings. Only username, avatar and house are public.

06House Cup

The same final-rank points go to houses, but split: a team's points are divided equally between its playing members, and each share goes to that member's house. Mixed-house teams count fairly for every house. Events marked House Cup only allow one house per team, so that house takes the full amount.

house share = points for the team's final rank ÷ number of playing members

Example: a BGMI squad of 3 Gir players and 1 Corbett player finishes 1st (10 points) → Gir 7.5, Corbett 2.5. Each of the four players still gets 10 Arena points.

08Organiser checklist

  1. Create the event from its game. Check the placement table, the per-kill points and the House-points table, then set it to Open.
  2. When registration closes, count the entries N and choose the format from section 03 (groups, bracket size, Swiss rounds, heats).
  3. After each match, go to Admin › Events › Results and paste one row per team: team name, username or in-game ID, place and kills. If any row is wrong, nothing is saved and every problem is listed.
  4. Made a mistake? Enter the same match label again and tick Replace, or delete the match. Every change is recorded in the audit log.
  5. Penalties, bonuses or no-shows: use the entry's points adjustment with a note, or disqualify the entry.
  6. When the last result is in, set the event to Completed. Arena points and House points update immediately.

Edge cases

  • No-show: leave the team out of the match. It gets 0 for that match.
  • Sub plays: results belong to the team. Player and house points count only the non-sub roster.
  • Same team twice in one match: rejected automatically.
  • Event cancelled: no points for anyone. Only completed events count.
  • Tie that must be broken (for example the last qualifying spot): use the game's tie-break column on page 4, or a decider match, and record it with a +0.01 adjustment and a note.
